Proteus — Logo Spec

Construction, color, and typography reference for the Proteus mark.

Concept

The mark is a portrait quad split into its two constituent triangles — the base primitive of a GPU render pipeline. One triangle renders solid; the other carries a diagonal hatch, reading as a textured / in-progress surface. The pairing nods to Proteus's core idea: components that are rendered, and metamorphic — never static.

Geometry

Drawn on a 104 × 144 unit grid (aspect ratio 13:18, portrait). Two triangles split by the diagonal from the top-left corner (0,0) to the bottom-right corner (104,144):

  • Triangle A (solid) — points (0,0), (0,144), (104,144): the bottom-left half.
  • Triangle B (hatched) — points (0,0), (104,0), (104,144): the top-right half.
  • No stroke or fill is drawn along the shared diagonal — the mark is rendered on a fully transparent canvas, so the seam and every hatch gap are true alpha transparency, not a color match to an assumed background. This is what makes the SVG/PNG assets safe to drop on any surface.

Minimum clear space around the mark: half the mark's width on all sides. Minimum size: 20px tall in digital use (favicon/app-icon exceptions aside).

The hatch fill

Drawn as a set of parallel diagonal strokes, all in the triangle's own color, clipped to triangle B. Each stroke is 8 units wide; strokes repeat on a 10.5-unit pitch (perpendicular spacing), leaving a 2.5-unit fully transparent gap between them — no background-colored line is ever drawn.

// stroke pitch = 10.5 units, stroke-width = 8 units, at 45°
for each k: draw a line through point (5.25k, 5.25k)
  perpendicular to the diagonal, stroke="{triangleColor}"
  stroke-width="8", clipped to the triangle-B polygon

{triangleColor} is the only color in the mark — deep violet on light, light violet on dark (see below). Every gap, on every treatment, is real alpha transparency, never a solid background color. (Note: an SVG <pattern> tiling approach was tried first but rendered incorrectly once exported as an image/PNG — explicit strokes render reliably everywhere.)

Typography

Wordmark: Inter, weight 700, all caps, letter-spacing 0.06em, set in the same color as the mark. Minimum companion mark height: keep the mark's cap-height roughly equal to the wordmark's cap-height, gap of 12–16px between mark and wordmark at logo-lockup scale.

Variants & usage

  • Color / light — Deep Violet mark, transparent background, for light surfaces.
  • Color / dark — Light Violet mark, transparent background, for dark surfaces.
  • Monochrome / on white — Ink mark, transparent background, for single-color contexts on light surfaces.
  • Monochrome / on black — Off-white mark, transparent background, for single-color contexts on dark surfaces.

All four are exported with a fully transparent background — the "light"/"dark" in the name refers to the mark's own color, chosen for contrast against that kind of surface, not a painted backdrop. Don't recolor the mark outside this set, don't separate the two triangles, don't add drop shadows or outlines, don't stretch off the 13:18 aspect ratio.
