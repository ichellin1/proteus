# proteus-ui

The Proteus component model and transition engine, built on `bevy_ecs`.

Part of [Proteus](https://github.com/ichellin1/proteus).

Apps don't use it directly: [`proteus-sdk`](https://crates.io/crates/proteus-sdk) is what you build an app with, and re-exports the types from here that an app needs. See the [guides](https://github.com/ichellin1/proteus/tree/main/docs).
