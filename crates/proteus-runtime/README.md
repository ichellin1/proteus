# proteus-runtime

Runs a Proteus app on a GPU surface: the `App` trait an app implements, the engine that runs it, and its settings, `ProteusConfig`.

Part of [Proteus](https://github.com/ichellin1/proteus).

An app uses it with [`proteus-sdk`](https://crates.io/crates/proteus-sdk) and a host: [`proteus-host-winit`](https://crates.io/crates/proteus-host-winit) natively, or [`proteus-host-web`](https://crates.io/crates/proteus-host-web) in a browser. See [Getting started in Rust](https://github.com/ichellin1/proteus/blob/main/docs/getting-started/rust.md).
