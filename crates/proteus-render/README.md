# proteus-render

Proteus's GPU renderer: the instanced quad pipeline, its shader and the texture atlases.

Part of [Proteus](https://github.com/ichellin1/proteus).

Apps don't use it directly: [`proteus-sdk`](https://crates.io/crates/proteus-sdk) is what you build an app with. See the [guides](https://github.com/ichellin1/proteus/tree/main/docs).
