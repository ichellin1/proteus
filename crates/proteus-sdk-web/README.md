# proteus-sdk-web

WebAssembly bindings that expose `proteus-sdk` to JavaScript, for the Proteus TypeScript SDK.

Part of [Proteus](https://github.com/ichellin1/proteus).

Apps don't use it directly. In TypeScript, use the [`proteus-sdk` npm package](https://www.npmjs.com/package/proteus-sdk), which is built from it; in Rust, use [`proteus-sdk`](https://crates.io/crates/proteus-sdk).
