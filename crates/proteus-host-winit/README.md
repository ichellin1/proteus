# proteus-host-winit

Runs a Proteus app in a native desktop window, with winit and wgpu.

Part of [Proteus](https://github.com/ichellin1/proteus).

`proteus_host_winit::run(app, RunConfig::default())` opens the window and runs the app until it's closed. See [Getting started in Rust](https://github.com/ichellin1/proteus/blob/main/docs/getting-started/rust.md), and the [guide to hosts](https://github.com/ichellin1/proteus/blob/main/docs/guides/hosts.md).
