# proteus-gpu

GPU setup for Proteus hosts: a wgpu device, queue and surface for a window or canvas.

Part of [Proteus](https://github.com/ichellin1/proteus).

Apps don't use it directly: a host, `proteus-host-winit` or `proteus-host-web`, uses it to set up the GPU. To build an app, see [`proteus-sdk`](https://crates.io/crates/proteus-sdk) and the [guides](https://github.com/ichellin1/proteus/tree/main/docs).
